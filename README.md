# ok-helper

Кроссплатформенный (приоритет — Windows) помощник для работы с треками
и путевыми точками (`.gpx`, `.plt`, `.wpt`). Интерфейс — **GUI на
PySide6 (Qt 6)**.

Умеет:

- переименовывать файлы из «скачанных» имён в формат `ГГГГММДД_Позывной`
  с нормализацией позывного;
- создавать локальные папки прямо из дерева файлов;
- переносить локальные файлы между папками;
- копировать имя выделенного элемента в буфер;
- синхронизировать статус «уже на FTP» между локальной папкой и сервером;
- просматривать, обновлять и удалять файлы на FTP-сервере;
- загружать файлы на FTP-сервер;
- следить за изменениями директории (watchdog, автообновление);
- работать в светлой или тёмной теме, включая автоопределение системной.

## Возможности

### Современный интерфейс

- Оформление на Qt-стиле **Fusion** с кастомным QSS: скруглённые панели,
  акцентные кнопки, hover-эффекты, подсветка активной вкладки,
  состояния `disabled`/`focus`/`pressed`, собственные шеврон списка и
  отметка чек-бокса (без внешних ресурсов).
- Палитра на холодных нейтралях, отдельные тона для рамок полей и
  разделителей; светлая и тёмная темы согласованы по контрасту.
- Верхний toolbar с иконками и текстом; набор кнопок зависит от
  активной вкладки:
  - **Файлы** — Вверх, Обновить, Исправить все, Папка,
    Переименовать, Переместить, Копировать имя, На FTP,
    В проводнике, Проверить загрузки;
  - **FTP** — Подключиться, Обновить, Копировать имя,
    Загрузить сюда…, Удалить.
  Кнопка «Журнал» общая для обеих вкладок. Иконки — системные глифы
  Qt, дополнительных файлов ресурсов проект не требует.
- Меню (Файл / Правка / FTP / Вид / Справка) с горячими клавишами и
  иконками.
- Панель журнала — **сворачиваемый док внизу окна**; журнал можно
  скрыть (**Ctrl+L**), состояние и высота запоминаются.
- Статусбар: сообщение о текущей операции слева, счётчики файлов,
  ошибок и заливок плюс корень дерева — справа.
- Размеры и положение окна, высота журнала и ширины колонок
  сохраняются в конфиге при закрытии окна.
- Предсказуемые отказы (не тот формат файла, нет папки) показываются
  неблокирующей плашкой над содержимым; `blocking_errors = true`
  возвращает модальные окна.
- Цветные статусные пометки прямо в дереве.
- Тема интерфейса: `auto / light / dark` (в F10). `auto` на Windows
  читает системную из реестра (`AppsUseLightTheme`).
- Мелкие элементы темы (галочка чек-бокса, стрелки раскрытия папок и
  выпадающих списков) рисуются в PNG при первом запуске темы и
  кладутся в `icons/` рядом с конфигом. Qt не умеет читать `data:`-URI
  в таблице стилей, поэтому картинки именно файловые; без прав на
  запись используется временный каталог, а при полном запрете записи
  интерфейс работает без этих отметок.

### Дерево файлов

- Рекурсивное дерево с ленивой подгрузкой.
- Двойной клик по папке — раскрыть / свернуть.
- Двойной клик по файлу — контекстное меню с доступными действиями
  (Открыть, Переименовать…, Переместить…, Копировать имя),
  «Копировать путь» и «Показать в проводнике»; файл открывается
  системным приложением пунктом «Открыть».
- Enter на папке — сделать её корнем дерева.
- Переходы по дереву (Enter, «Вверх», «Обзор…») меняют только
  отображаемый корень: корневая папка из настроек (`root_dir`) при
  этом не переписывается и задаётся в F10.
- Правый клик — контекстное меню.
- «Показать в проводнике» (**Ctrl+E**) открывает системный файловый
  менеджер с выделенным элементом: на Windows — Проводник
  (`explorer /select,"путь"`), на macOS — Finder, на Linux — папка
  через `xdg-open`. Кавычки ставятся только вокруг пути: если путь с
  пробелами уйдёт одним аргументом, Проводник не распознаёт ключ
  `/select` и открывает «Документы».
- Автообновление при изменениях на диске.
- Выделение не теряется при перестройке дерева (watchdog, перенос,
  правка имени, загрузка на FTP): действия на панели инструментов
  работают по выбранному файлу сразу после одного клика. После
  переименования выделение переходит на новое имя.
- Цветовые пометки: папки — оранжевые; ошибки — красные; уже залитые
  на FTP — зелёные, со пометкой `✓ на FTP`.

### Журнал

- Показывает операции, предупреждения и ошибки с отметкой времени.
- Панель внизу окна: длинные записи переносятся с висячим отступом, а
  не уезжают под колонку времени.
- Прокручивается вниз только если вы уже внизу — чтение истории не
  срывается новыми записями.
- Кнопки панели: «Копировать журнал» (**Ctrl+Shift+L**), «Сохранить в
  файл…» (`Правка → Сохранить журнал в файл…`) и «Очистить».
- Панель скрывается кнопкой «Журнал» в toolbar или **Ctrl+L**.

### Создание папок

- **Ctrl+N** — открыть диалог.
- **В корне** (совпадает с `root_dir` из настроек): имя
  предзаполняется текущей датой `ГГГГ-ММ-ДД_`; доступен чек-бокс
  `Создать внутри 10-Tracks`.
- Во вложенных папках поле имени пустое, чек-бокса нет.
- `Ctrl+T` в поле — транслит на латиницу.

### Перенос файлов между папками

- **Ctrl+X** — открыть диалог.
- В диалоге — дерево папок для навигации; двойной клик — войти,
  `↑ Вверх` — выйти, кнопка `Переместить сюда` — выполнить перенос.
- Работает только для локальных файлов.

### Переименование

- **F2** — открыть диалог: «Было», «Предложение» (автоправка), поле
  ввода с предзаполнением.
- `Ctrl+T` — транслит + нормализация позывного.

### Копирование имени (Ctrl+Y)

- В дереве «Файлы» — имя файла или папки.
- В списке FTP — имя объекта на сервере.

### Папка загрузок

Слежение включается в F10 («Следить за папкой загрузок») или в меню
**Загрузки** — там же ручная проверка (**Ctrl+D**) и «Открыть папку
загрузок».

- Когда в папке появляется новый `.gpx`, `.plt` или `.wpt`, сервис
  предлагает перенести его в корень дерева или выбрать папку.
- Если в открытой сейчас папке (корне дерева) есть **дочерняя** папка
  `10-Tracks` ровно на один уровень вложенности (`папка_а/10-Tracks` —
  да, `папка_а/папка_б/10-Tracks` — нет), перенос предлагается именно
  в неё. Если такой папки нет — прежняя логика: корень дерева или
  выбор папки вручную.
- Временные файлы браузеров (`.crdownload`, `.part`, `.tmp`,
  `.download`, `.partial`, `.opdownload`) готовыми не считаются:
  уведомление приходит после переименования в рабочий формат.
- Папка проверяется и по событиям файловой системы, и дополнительно
  каждые 3 секунды. События могут не дойти на сетевом диске, в
  OneDrive или после сна машины — периодическая проверка это
  закрывает, а `Ctrl+D` проверяет папку вручную.
- Файлы, скачанные до запуска сервиса, не предлагаются: иначе при
  каждом старте всплывало бы всё содержимое папки. Допуск в одну
  секунду — чтобы не потерять файл, скачанный в момент запуска.
- Состояние слежения всегда видно в журнале: включено (с путём),
  выключено или папка недоступна.

### Проверка и переименование имён

Для `.gpx` и `.plt` — формат `ГГГГММДД_Позывной`.

**Нормализация позывного:**

- первая буква — заглавная (`lisa` → `Lisa`);
- хвостовой номер (1–4 цифры после букв) — минимум 2 разряда,
  разделитель `_`/`-` перед ним убирается. Номер может быть как в
  конце, так и в середине:
  - `lisa_1` → `Lisa01`
  - `lisa1` → `Lisa01`
  - `lisa-1` → `Lisa01`
  - `lisa_12` → `Lisa12`
  - `Lisa_03_Test` → `Lisa03_Test`
  - `Lisa_04_1` → `Lisa04_1`
- если база уже оканчивается цифрой (`Lisa01_1`), хвостовая группа
  не трогается.

**Дата из содержимого `.gpx`.** Если в имени `.gpx` даты нет, сервис
читает последние ~256 КБ файла и берёт дату из последней `<time>`.

Для `.wpt` — только `Waypoints_ГГГГММДД`. Файлы `<1-4 цифры>m.gpx`
(`100m.gpx`) не проверяются.

### Работа с FTP

**Автоподстановка пути.** На вкладке FTP есть чек-бокс «Следить за
папкой из вкладки «Файлы»». Если включён, при переходе на вкладку FTP
сервис ищет вверх по дереву папку вида `ГГГГ-ММ-ДД_Место` от
выделенного элемента (или от корня, если ничего не выделено),
подставляет её в путь и загружает листинг.

**Синхронизация с локальной папкой.** После каждой загрузки листинга
папки на FTP локальные файлы с такими же именами (в папке с
совпадающим именем) помечаются зелёной галочкой `✓ на FTP`. Сверка
обновляется:

- при каждой загрузке листинга (кнопка «Обновить», двойной клик);
- после каждой успешной загрузки файла на FTP.

**Отправка (F12 или `⇪ FTP`):**

- `.plt` — с корректным именем;
- `.wpt` — только `Waypoints_ГГГГММДД`;
- `.gpx` — **только** `<1-4 цифры>m.gpx`;
- файлы из папки `10-Tracks` — запрещены;
- папка назначения обязательна.

**Удаление (Del во вкладке FTP):** только при `ftp_readonly = false`,
с диалогом подтверждения.

**Режим эмуляции.** `ftp_readonly = true` — сервис подключается,
читает папки, но **не создаёт**, **не загружает** и **не удаляет**
файлы.

## Клавиши

| Клавиша | Действие |
|---|---|
| `F1` | Справка |
| `F2` | Переименовать (вкладка «Файлы») |
| `F5` | Обновить список |
| `Ctrl+F5` | Исправить все |
| `Ctrl+N` | Создать папку |
| `Ctrl+O` | Выбрать директорию |
| `Ctrl+X` | Переместить файл (вкладка «Файлы») |
| `Ctrl+Y` | Копировать имя |
| `Ctrl+Shift+C` | Копировать полный путь |
| `Ctrl+E` | Показать файл в проводнике |
| `Ctrl+L` | Показать / скрыть панель журнала |
| `Ctrl+Shift+L` | Копировать весь журнал |
| `Ctrl+D` | Проверить папку загрузок |
| `Ctrl+1` / `Ctrl+2` | Вкладка «Файлы» / «FTP» |
| `F10` | Настройки |
| `F12` | Загрузить на FTP (вкладка «Файлы») |
| `Delete` | Удалить на FTP (вкладка FTP) |
| `Ctrl+Q` | Выход |
| `Ctrl+T` (в диалогах) | Транслит в поле ввода |
| `Enter` (на папке) | Сделать корнем дерева |
| `Двойной клик` (на папке) | Раскрыть / скрыть |
| `Двойной клик` (на файле) | Меню действий (Копировать имя / Копировать путь / Показать в проводнике / Переименовать / Переместить / Открыть) |
| `Правый клик` | Контекстное меню |

Команды с пометкой «вкладка «Файлы»» работают только на этой вкладке:
на вкладке FTP они показывают напоминание вместо диалога для
локального файла.

## Установка

Требуется **Python 3.11+** и **PySide6**.

```bash
git clone https://github.com/<ваш-логин>/ok-helper.git
cd ok-helper
python -m venv .venv

# Windows (PowerShell):
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
python main.py
```

Можно указать директорию сразу:

```bash
python main.py /path/to/tracks
```

## Настройка

Все настройки — в TOML-файле:

| ОС | Путь |
|---|---|
| Windows | `%APPDATA%\ok-helper\config.toml` |
| Linux | `~/.config/ok-helper/config.toml` |
| macOS | `~/Library/Application Support/ok-helper/config.toml` |

Правятся через **F10** или вручную:

```toml
root_dir        = 'C:\Users\you\Tracks'
downloads_dir   = 'C:\Users\you\Downloads'
watch_downloads = false
theme           = 'auto'   # auto | light | dark

ftp_host        = 'ftp.example.com'
ftp_port        = 21
ftp_user        = 'username'
ftp_password    = 'secret'
ftp_path        = '/upload'
ftp_readonly    = false

help_visible_at_start = true
first_run = false

# --- состояние интерфейса (пишется автоматически при закрытии) ---
window_geometry     = '1000,700,10,20'   # ШxВ+X+Y; пусто — по умолчанию
tree_column_widths  = '300,80,120'       # ширины колонок дерева
log_visible         = true               # показывать панель журнала
log_dock_height     = 180                # высота панели журнала, px
blocking_errors     = false              # отказы — плашкой, а не окном
```

Ключи состояния интерфейса можно удалить: тогда окно откроется с
размерами по умолчанию, а колонки снова станут «по содержимому».
Ключ `splitter_state` остался от версии с журналом слева: он больше не
используется и записывается пустым.

Пути пишите в **одинарных** кавычках, если они содержат `\`:

```toml
root_dir = 'C:\Users\you\Tracks'   # правильно
root_dir = "C:\Users\you\Tracks"   # ошибка TOML
```

## Разработка

### Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest -v
```

Маркеры: `analyzer`, `ftp`, `translit`, `folder`, `path_walk`, `upload`,
`clipboard`, `handlers`, `config`, `theme`, `gui`, `main`, `smoke`.
Пример: `pytest -m "ftp and smoke"`.

GUI-тесты не требуют экрана: `conftest.py` выставляет
`QT_QPA_PLATFORM=offscreen`, а модальные окна, FTP-задачи и
watchdog-наблюдатели в тестах подменяются. FTP-клиент проверяется на
мини-эмуляции `ftplib.FTP`, поэтому реальный сервер не нужен.

### Сборка портативной версии

Локально:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ok-helper main.py
```

Готовый `.exe` появится в `dist/`. Артефакт `ok-helper-windows` из
GitHub Actions содержит ту же сборку.
